## About

배운 내용을 그냥 흘려보내지 않기 위한 개인 학습 기록 저장소입니다.

개념을 처음 배운 날의 언어로 정리하고, 헷갈렸던 부분은 다시 봤을 때 바로 떠올릴 수 있게 예제와 풀이 흐름을 함께 남깁니다. 알고리즘 문제는 복습하기 쉽도록 문제 이름이 아니라 알고리즘 유형별로 정리하고 있습니다.

## My Rules

- 배운 내용은 나중의 내가 다시 읽어도 이해할 수 있게 정리하기
- 문제 풀이는 코드만 두지 말고 핵심 아이디어와 실수 포인트를 남기기
- 오래된 내용은 현재 폴더 구조와 학습 흐름에 맞춰 계속 다듬기
- 미완성 코드와 연습 조각은 정리하거나 과감히 비우기
